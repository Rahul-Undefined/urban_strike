track.mp3 — the game's one recorded piece of music (v2.15.0)

What it is     "LUZ ROJA (Instrumental - Sped Up)" by bxkq, supplied by the
               project owner on 21 Nov 2026 as a 320 kbps mp3 and re-encoded
               here to 96 kbps stereo (1.2 MB) for streaming.

LICENCE        This is a commercial recording. Shipping it in a public game or
               a public repository needs the rights holder's permission. That
               permission is the project owner's to obtain; nothing in this
               repository grants it. Without it, replace the file.

How to swap    1. Put any mp3 here under the same name (96 kbps is plenty).
               2. In public/src/audio/track.js set DROP to the second where
                  the new track's bass lands. The match countdown is cut so
                  that moment falls on zero. A track with no drop: use 5.
               Nothing else in the game knows what the song is.

Where it plays menu and lobby (quiet loop), the match countdown through the
               first seconds of play (then it fades out), and as the radio in
               a vehicle somebody is driving (B switches the radio).
